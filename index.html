01 — hikâye

Dört yıl önce bir merakla başladı.

terminal / raufix@baba

yazı hazır

Her şey “bu buton neden ortalanmıyor?” sorusuyla başladı. HTML ve CSS ile açtığım ilk sayfadan bu yana dört yıl geçti. O gün tek bir dosyaydı; bugün Android uygulamaları, web projeleri ve Minecraft modları aynı masada duruyor.

Java ve Kotlin ile Android tarafında native uygulamalar geliştiriyorum: arayüzler, REST entegrasyonları, arka plan servisleri, imzalı APK'lar. Web tarafında HTML, CSS, JavaScript ve PHP ile uçtan uca işler çıkarıyorum. Boş kaldığımda Forge ve Fabric ile Minecraft'a kendi kurallarımı yazıyorum.

Birçok dil biliyorum — Java, Kotlin, JavaScript, TypeScript, PHP, Python, C#, Lua, SQL — ama asıl mesele dil değil, problemi çözme biçimi. Gece 03.00'te build almak, sabah ilk iş deploy etmek benim için normal. Kod yazmak yetenek işi değil, inat işi.

“Denk olan kimse yok.”

— düşmanlarım prim kasıyor :d
